Settings

Display

Press M in the panel to switch.
0 shows labels only (rows without a label still show text).

Behaviour

0 = off. The old userscript refetched every 1.5 s; this only fills gaps auto-refresh misses.
claude.ai's new layout removed its own arrows. Clicking one reloads the chat onto that branch (this tab only).

Document vault

Saved on this computer when you open a chat. Files Claude makes are captured per branch before another branch can overwrite them.

Keyboard shortcut

Default Alt+B. Change it at chrome://extensions/shortcuts (Chrome doesn't let extensions open that page for you).

Labels & stars backup

Labels, stars and collapsed rows are stored on this computer only. Back them up before reinstalling.
